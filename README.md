# 🏥 Virtual Exams

Sistema desktop desenvolvido em **Java** para o gerenciamento de exames médicos, consultas e pacientes, criado para aplicar conceitos fundamentais de programação e boas práticas de desenvolvimento.

## 🚀 Tecnologias e Recursos Utilizados
* **Linguagem Java**: Lógica de programação e estruturação orientada a objetos (**Java POO**).
* **Interface Gráfica (GUI)**: Construção de telas e diálogos interativos utilizando **Java Swing** e **JOptionPane**.
* **Banco de Dados Relacional**: **MySQL** para persistência de dados, modelagem de tabelas e relacionamentos.
* **Padrão DAO (Data Access Object)**: Separação de responsabilidades, isolando os comandos SQL e centralizando as operações nas classes `UsuarioDAO` e `ExameDAO`.
* **Segurança e Criptografia**: Implementação de hash **SHA-256** para o armazenamento seguro de senhas de usuários.
* **Manipulação de Arquivos**: Suporte para salvamento e leitura de arquivos (PDF/XML) diretamente em formato `BLOB` no banco de dados.

## 💡 Sobre o Projeto
O projeto foi estruturado com foco em organizar o fluxo de dados entre as telas e o banco de dados, garantindo uma base sólida em POO, tratamento de exceções e segurança da informação.
